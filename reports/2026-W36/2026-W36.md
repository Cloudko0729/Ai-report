## 本週最值得注意

### 1. 🚨 OpenAI Astra 正式發布：史上第一個「Critical 級」資安能力模型上市（09-03）

W33 那條線收尾了，但結果比「延後上市」更值得注意——**它上市了，而且是帶著 Critical 標籤上市的**。

**能力（OpenAI 自己公布的）：**
- **首個跨過 Preparedness Framework「Critical 資安門檻」的模型**
- 可**自主發現前所未知的安全弱點、並對防護良好的系統建構出可用的 exploit**，過程無需人類逐步指導
- **ExploitBench 拿到滿分**
- 在改造過的測試中**自主找出並利用了兩個 zero-day**
- 另有電腦操作、科學能力的大幅提升，OpenAI 稱其為「電腦與瀏覽器使用的新前沿」

**上市方式——這才是重點：**
| 階段 | 對象 |
|---|---|
| 09-03 首發 | 僅限 **Daybreak** 資安計畫參與者（即 W33 報導的申請制方案） |
| 接下來一週 | 逐步開放付費方案（Pro / Plus / Enterprise / Business）與 API |
| 最強資安能力 | **持續限定給選定夥伴**，不隨一般方案開放 |

**配套防護：**
- **chain-of-thought 監控**：偵測並攔阻不當行為
- **jailbreak 偵測**與**containment-escape（逃脫圍堵）評估**
- **對評估為高風險的帳號限制 Astra 的回應**
- OpenAI 稱 Astra 是其「**迄今最對齊的模型**」

**對你的意義：** 這件事的意義不在你會不會用到 Astra，而在**它確立了一個先例**：能力達到危險等級的模型不再是「不發布」，而是「發布但分層管制」。W33 我寫過這是「未來高風險能力的商業模式」，本週它從推測變成事實。同時也意味著——**同等級的攻擊能力已經存在於世界上**，這正好呼應 W35 那 116 家公司「時間窗口有限」的警告。

### 2. ⚡ Claude Code 週額度 09-14 變動：帳面「+25%」，但對你是「-17%」（08-29 公告）

**這則直接影響你。** 需要看懂數字怎麼算：

| 時間點 | 額度水準 |
|---|---|
| 原始基準 | 100% |
| 2026-05 至今（+50% 促銷） | **150%** ← 你現在用的 |
| **2026-09-14 起（永久）** | **125%** |

Anthropic 的公告主打「**永久調高 25%**」（相對原始基準確實是），但**相對你現在實際擁有的額度，這是 17% 的減少**（125 ÷ 150 ≈ 0.83）。

- 適用：Pro、Max、Team、seat-based Enterprise
- **+50% 促銷維持到 09-13**，09-14 起切換
- 社群批評這個公告「強調增加、淡化淨減少」，Anthropic 員工也承認**訊息呈現方式可以更清楚、應該先講變動本身**

**同批更新：** 輸入載入速度加快，並預告更好的用量檢視工具。

**對你的意義：** 你每週跑週報 pipeline（WebSearch + NotebookLM + podcast 生成），屬於會吃額度的用法。**09-14 之後可用量會比現在少約 17%**——如果你之後感覺額度變緊，這就是原因，不是錯覺。實務建議：這兩週如果有大型任務（例如那個 MOSS-ASR 實測），排在 09-13 前跑完比較划算。

### 3. 🎭 Claude Fable 5.1 / Mythos 5.1：同一顆模型，兩種安全等級（09-01）

Anthropic 發布新旗艦，距 Fable 5 三個月。

**關鍵設計：** **Fable 5.1 與 Mythos 5.1 是同一顆模型，差別只在安全防護等級**——
- **Fable 5.1**：所有人皆可用
- **Mythos 5.1**：僅限**美國境內**、參與 Anthropic 信任存取計畫（trusted access programs）的企業與個人

**效能：** Anthropic 稱其為「世界上最先進的 coding 與知識工作模型」，在多項 benchmark 上勝過 Fable 5、Opus 5 與 OpenAI 的 GPT-5.6 Sol。Fable 5.1 相對 Fable 5 的進步幅度（130 分）**大於 Opus 5 相對 Fable 5 的進步（101 分）**。

**定價——有一個實際的好消息：**
- 主要費率不變：**$10 / $50** 每百萬 input/output tokens（與 Fable 5 相同）
- **cache 定價砍 75%**，cache-read 降到 **$0.25 / 百萬 tokens**

**對你的意義：** cache 降價 75% 對**重複讀取同一批脈絡**的工作最有感——例如你的週報 pipeline 每次都要載入相同的 memory 與專案脈絡。如果你有用 API 跑批次任務，這是實質的成本下降。至於 Fable/Mythos 的分層設計，正是本週主線：**同一顆模型的能力天花板一樣，差別在誰被允許用到那個天花板**。

### 4. 🔖 Claude 浮水印進入旗艦模型——EU AI Act 合規從條文變成產品

W32 起追蹤的歐盟 AI Act 執法線，本週有了具體產品層面的落地：

- **2026-08-02 之後發布的 Claude 模型都內含浮水印**——因此 **Fable 5.1 / Mythos 5.1 是首批帶著浮水印出廠的旗艦模型**
- 這是為符合 **AI Act 第 50 條**的透明度要求，Anthropic 已簽署歐盟《AI 生成內容透明度行為準則》
- **技術做法**：文字嵌入**肉眼不可見的機器可讀訊號**，正常閱讀看不出來；**複製貼上後浮水印仍在**，部分標記預期能在編輯後存活。檔案則另用基於 **C2PA 標準**的簽章式來源中繼資料
- **全球適用**，不限歐洲用戶
- 舊版 Claude 模型不會立即比照辦理，Anthropic 表示會在 AI Act 過渡期內補上

**歐盟執法現況（連續第 5 週追蹤）：** AI Office 已從「寫指引」轉為「主動調查」，**德國、法國、荷蘭的國家市場監督機關已展開正式調查**；AI Office 計畫於 **2026 年 9 月成立兩個工作小組**，讓簽署方分享實作做法並回饋透明度措施。**仍無經證實的公開罰單。**

**對你的意義：** 你的週報是用 Claude 寫的，內容會帶浮水印。**這對你沒有實務影響**（不影響閱讀、不影響 GitHub 發布），但值得知道：你產出的文字現在技術上是可被識別為 AI 參與生成的，而且**複製貼上不會去掉**。如果你哪天需要說明內容來源，這反而是個誠實的佐證。

### 5. 🛡️ OpenAI Defense Factory：把「找漏洞→修補」變成自動化迴圈

配合 Astra 發布，OpenAI 推出 **The Defense Factory**——一條自動化流程，能夠：

**繪製系統結構 → 獵捕漏洞 → 在隔離環境測試 exploit → 驗證修補是否有效**

**對你的意義：** 這是 W35 那封「防禦衝刺」公開信的具體回應之一。攻防兩端都在自動化——**Astra 讓攻擊自動化，Defense Factory 讓防守自動化**。對個人開發者而言，這類工具普及後，「相依套件有沒有已知漏洞」這種檢查的成本會大幅下降。
