## 本週最值得注意

### 1. 🚀 Claude Opus 5 發表：近 Fable 5 智慧、Opus 4.8 的價格（2026-07-23~24）

本週頭條：Anthropic 推出 **Claude Opus 5**，主打「**逼近 Fable 5 的前沿智慧，但只要 Opus 4.8 的價格**」，定位為高效處理職場任務的旗艦。

**技術規格：**
- **1M token context window**
- 新增 **xhigh 推理強度**模式，支援 per-turn 控制
- 安全備援：可 fallback 到 Claude Opus 4.8
- **定價 $5 / $25 per 1M tokens（input/output）**——與前代 Opus 4.8 相同，等於同價換到大幅升級的效能

**Benchmark 亮點：**
- **Frontier-Bench v0.1（軟體工程）**：超越所有受測模型，較 Opus 4.8 效能翻倍以上、每任務成本更低
- **CursorBench 3.2**（最大 effort）：距 Fable 5 峰值僅差 0.5%，成本卻只有一半
- **ARC-AGI 3**（新問題解決）：比次佳模型高 3 倍
- **Zapier AutomationBench**（端到端商業任務）：同成本下通過率約為次佳模型的 1.5 倍
- 即使在最低 effort 下，跑商業工作流仍比其他模型高 effort 完成更多任務
- 弱項：cybersecurity 任務仍落後 Mythos 5
- 招牌案例：Frontier-Bench 有一題要求從「看不到的圖」重建 3D CAD 零件，Opus 5 自己寫了一條 computer vision pipeline 從原始像素抽取幾何、且反覆成功，其他模型 5 次嘗試都失敗

**對你的意義：** 如果你在 Claude Code / API 上跑 coding 或 agent 任務，Opus 5 是「同價升級」——不必加預算就換到更強的模型。留意 xhigh effort 會吃更多 token，per-turn 控制可以按需切換。cybersecurity 場景才需要考慮 Mythos 5。

延續 W29，Google 的 **Gemini 3.5 Pro 又延期**——07-17 目標落空後，最新洩漏指向**延到 8 月**。目前 Google 公開 API 模型清單仍沒有 gemini-3.5-pro，官方 help 頁只描述 Flash。

**對你的意義：** Google 旗艦持續難產，Opus 5 又在同週上市，三大廠差距進一步拉開。導入 Gemini 的時程假設要繼續往後拉，改以「重建後實測」為準。

- **Claude 語音模式擴充（07-23）**：改跑 Opus / Sonnet / Haiku，可接 Gmail、Slack 等工具，支援更多語言；預設用你上次在文字對話用的模型的最快版本
