1. 🚀 Claude Opus 5 發表：近 Fable 5 智慧、Opus 4.8 的價格（2026-07-23~24）

本週頭條：Anthropic 推出 Claude Opus 5，主打「逼近 Fable 5 的前沿智慧，但只要 Opus 4.8 的價格」。

技術規格：

  • 1M token context window
  • 新增 xhigh 推理強度模式，支援 per-turn 控制
  • 安全備援：可 fallback 到 Claude Opus 4.8
計費項目Opus 5對比
Input$5 / 1M tokens與 Opus 4.8 同價
Output$25 / 1M tokens與 Opus 4.8 同價

Benchmark 亮點：

  • Frontier-Bench v0.1（軟體工程）：超越所有受測模型，較 Opus 4.8 效能翻倍以上、每任務成本更低
  • CursorBench 3.2（最大 effort）：距 Fable 5 峰值僅差 0.5%，成本卻只有一半
  • ARC-AGI 3（新問題解決）：比次佳模型高 3 倍
  • Zapier AutomationBench（端到端商業任務）：同成本下通過率約次佳模型的 1.5 倍
  • 弱項：cybersecurity 任務仍落後 Mythos 5
  • 招牌案例：從「看不到的圖」重建 3D CAD 零件，Opus 5 自己寫 computer vision pipeline 從像素抽幾何、反覆成功，其他模型 5 次都失敗
在 Claude Code / API 上跑 coding 或 agent 任務，Opus 5 是「同價升級」——不必加預算就換到更強的模型。xhigh effort 會吃更多 token，可用 per-turn 控制按需切換。cybersecurity 場景才需考慮 Mythos 5。

2. Gemini 3.5 Pro 第四度跳票，傳延到 8 月；Google 改先出 Flash Lite（07-21）

延續 W29，Gemini 3.5 Pro 又延期——07-17 目標落空後，最新洩漏指向延到 8 月。目前 Google 公開 API 清單仍沒有 gemini-3.5-pro。

  • Google 反而在 07-21 先推出 Gemini 3.5 Flash Lite（輕量快速版）
  • 延期原因延續上週：DeepMind 打掉重練，卡在幻覺率、遞迴 tool-calling 與複雜 SVG 生成
Google 旗艦持續難產，Opus 5 又在同週上市，三大廠差距進一步拉開。導入 Gemini 的時程假設要繼續往後拉，改以「重建後實測」為準。

  • ChatGPT Health（07-24）：美國合資格用戶串接健康紀錄 + Apple Health 到單一儀表板（web/iOS，18 歲以上 Free/Go/Plus/Pro）
  • ChatGPT Voice 進 Work 與桌面版 Codex（07-24）：語音直接用在研究產出與軟體開發

4. Anthropic 其他更新：語音模式擴充、經濟指標連接器、企業管理、API 汰除

  • Claude 語音模式擴充（07-23）：改跑 Opus/Sonnet/Haiku，可接 Gmail、Slack，支援更多語言
  • Anthropic Economic Index connector：探索「AI 如何被用在經濟活動」的資料
  • 企業管理強化：admin analytics、model-level entitlements、spend alerts；HIPAA 單一流程管理
  • Claude Code（07-17~18）：修正 permission-check 繞過、PowerShell/Bash 安全問題、背景 session bug；新增 EndConversation、進度 heartbeat、observability
  • API 汰除：Opus 4.7 的 fast mode 於 07-24 移除，speed="fast" 請求會回錯誤
語音模式現在能接 Gmail/Slack，適合當語音助理跑跨工具任務。若你有腳本呼叫 Opus 4.7 fast mode，07-24 起會壞掉要改。Claude Code 的 permission-check 修補建議盡快更新。

5. 開源模型：Kimi K3 登頂、Devstral 2 領先本地 coding

  • Kimi K3（Moonshot，07-16 發佈，本週熱度爆發）：2.8 兆參數 MoE、原生多模態、1M context——目前最大開放權重模型；Code Arena 奪冠、複雜任務超越部分閉源模型；完整權重排定 07-27 釋出
  • Devstral 2（123B）：SWE-bench Verified 72.2%，2026 年最強開放權重 coding 模型；Devstral Small 2（24B，Apache 2.0）消費級硬體可跑
  • Gemini 3.5 Flash Lite（07-21）：Google 輕量版本
開放權重陣營持續逼近前沿——Kimi K3 走「規模霸權」、Devstral 2 走「本地可跑的 coding 主力」。搭配 W28 的 GLM-5.2、W29 的 Inkling，可選項越來越強。Kimi K3 權重 07-27 出來後值得實測。
