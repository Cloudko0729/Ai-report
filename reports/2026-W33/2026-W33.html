本週主線 模型的「資安能力」同時變成煞車與商品。
同一家公司、同一週：OpenAI 因 Astra 的攻擊能力達到 Preparedness Framework 的 Critical 門檻而暫緩發布（08-07），三天後卻推出刻意移除資安護欄的 GPT-5.6-Cyber（08-10）。而 Anthropic 走了另一條路——用數據證明人類把關根本不可靠（攔截率 13.6%），把 Claude Code 的安全審查從人手交給分類器（08-14 起預設）。
🔥 本週最值得注意

1. ⚡ Claude Code auto mode 自 08-14 起成為預設（Pro / Max / Team）— 與你直接相關

本週對你最有實質影響的一則：每次工具呼叫都要你按「同意」的模式結束了，改由分類器即時審查每一次呼叫，判斷是否為不可逆、破壞性或越界的動作。

Anthropic 的理由是一份對照研究（1,053 名付費測試者）：

把關方式危險指令攔截率
人類審查13.6%
連續 50 個 prompt 之後的人類約 5%
auto mode 分類器89%

另外兩個數字更說明問題：

  • 使用者對權限提示的核准率高達 97%——這個人工檢查點多半已淪為肌肉記憶
  • Team 與 Enterprise 開啟 auto mode 後，PR 產出量增加約 25%

實務細節：分類器本身的 token 開銷不計入你的用量額度（Pro/Max/Team）。

同批 Claude Code 更新：預設 subagent forking、跨 session 的 mention 與 SendMessage 強化、GitLab 與 marketplace 支援加強、policy 與 gateway 驗證改善，以及 Remote Control、權限、網路、session 穩定性的一批修正。

這是權限模型的根本轉向——從「人類逐次批准」變成「AI 審查 + 事前規則」。你該做的是把真正不能碰的東西寫成 deny 規則，而不是繼續依賴自己在提示跳出來時會看清楚（數據顯示你不會，尤其在長 session 後）。

2. 🛑 OpenAI 因「資安能力過強」暫緩 Astra 發布（08-07）

上週才低調宣布的 Astra，本週踩了煞車——理由罕見：模型太會駭客。

  • 觸及 OpenAI Preparedness Framework 中最高風險等級「Critical」的網路安全能力門檻，無法排除
  • 具體風險：模型可能自主識別並對傳統上防護良好的真實系統發動攻擊
  • 白宮與監管機關已敦促該公司放慢腳步；OpenAI 主動告知政府其延後計畫
  • Sam Altman 表示 Astra 最終仍會「廣泛可用」，但需先擴大測試與安全防護
這是首次有前沿模型因為攻擊能力而非其他原因被自家公司叫停。對照 W32 的沙箱逃逸事件，「模型的網路安全能力」已正式成為發布的關鍵瓶頸。

3. 🔓 ...但同一家公司三天後推出「拆掉護欄」的資安模型（Daybreak Blue / Red，08-10）

與上一則形成強烈對比：OpenAI 把 Daybreak 資安計畫拆成兩個層級，其中一層是專門訓練、且刻意放寬限制的模型。

層級內容敏感請求回應率
Daybreak BlueGPT-5.6 Sol 移除系統層級資安護欄，供核可的防守方用於事件偵測與應變、調查、漏洞管理、安全評估2.0%
Daybreak Red全新專門訓練的 GPT-5.6-Cyber，供授權的漏洞研究、exploit 驗證、安全測試95.0%
（對照）一般 GPT-5.6 Sol—1.5%

「敏感請求」涵蓋 exploit chain 開發、身分驗證繞過、權限提升。

實際戰果：GPT-5.6-Cyber 找出 Chrome V8 引擎中兩個先前未知的漏洞，可串連起來破壞記憶體並繞過 V8 heap sandbox；Google 已修補，編號 CVE-2026-15903。
這兩則放在一起看很值得玩味——同一週，OpenAI 因為模型會駭客而暫緩旗艦發布，卻把「會駭客」本身做成了一條產品線。差別在於存取控制：Astra 面向所有人，Daybreak 限定核可對象。這預示了未來高風險能力的商業模式：不是不做，而是分層授權。

4. Google：Gemini 3.7 Flash 搶在 3.5 Pro 之前上市（08-13）

Google 的產品線出現一個奇特景象——新一代的 Flash 先出，上一代的 Pro 還沒出。

Gemini 3.7 Flash（08-13）：

  • 定位「最聰明的主力型號」，主打 coding 與 agent；距 3.6 Flash 僅三週
  • 較 3.6 Flash 在軟體工程、知識工作、網頁開發明顯進步，尤其除錯與首次產出即可用的程式碼準確度
  • 定價：至 2026-12-31 為 $0.75 / $3.75 per 1M tokens；2027-01-01 起翻倍至 $1.50 / $7.50
  • API、AI Studio、Antigravity、Gemini Enterprise 皆可取得；個人用戶經 Gemini app 的 Spark（Pro/Ultra）
  • Google 稱其在九項 benchmark 上勝過 Anthropic 與 OpenAI 同級模型

而 Gemini 3.5 Pro 仍然沒有出（連續第 6 週追蹤）：

  • 5 月 I/O 宣布、承諾 6 月推出，至今 DeepMind 模型頁仍標示「coming soon」
  • 延誤原因為實質的能力與部署問題：coding 表現不足、訓練資料更新令人失望，「落後數月」
  • Bloomberg 報導 Google 高層擔心 3.5 Pro 已不具競爭力
  • 本週 Google 再度大幅改組其成立十年的 AI 組織以加速決策與發布
Flash 線健康、Pro 線難產，代表 Google 目前能穩定交付的是中階模型。3.7 Flash 的年底優惠價確實划算，值得在成本敏感的 coding/agent 場景測試；但別再把 3.5 Pro 排進任何規劃。

7. 歐盟執法現況：已組建 38 人團隊，但尚未開罰

延續 W32 的追蹤，本週結論是「權力到位、動作未到」：

  • AI Office 已在布魯塞爾組建 38 人的執法團隊，獲授權訪談公司人員、調閱模型文件、撤銷不合規業者的歐盟市場准入
  • 與 OpenAI、Anthropic 的接觸仍屬雙邊初步溝通，尚未有任何正式罰單（截至 8 月中）
  • AI Act 第 50 條的透明度與標示義務（含合成內容浮水印）自 08-02 起可強制執行
上週說「透明度義務已生效」，本週補上執行力道的實況——有牙齒但還沒咬人。若你的產品涉及生成內容，浮水印/標示是現在就該做的合規項目。

🎯 本週與你高度相關的項目
選項 A — 本週最該做

立即：為 auto mode 設好 deny 規則

auto mode 已於 08-14 成為預設。數據很直白：人類攔截危險指令只有 13.6%，長 session 後掉到 5%，而且你有 97% 的機率直接按同意。與其依賴自己看提示，不如現在花十分鐘把絕對不能自動執行的操作寫成 deny 規則——例如涉及正式環境、刪除、對外發送、金鑰操作的指令。

選項 B — 成本

用 Gemini 3.7 Flash 做一次成本對照

年底前 $0.75/$3.75 比多數同級模型便宜。挑一個平常用 Claude 或 GPT 跑的中等 coding 任務跑一次，比較輸出品質與實際花費，評估是否值得把部分低風險工作分流過去（注意 2027 年起價格翻倍）。

選項 C — 趨勢觀察

觀察「高風險能力分層授權」這個新模式

Astra 暫緩 + Daybreak Red 限定授權，是同一套邏輯的兩面，很可能成為未來高風險 AI 能力的標準做法。若你的工作與資安沾邊，值得留意 Daybreak Blue 這類「給防守方的去護欄管道」是否會更廣泛開放。
