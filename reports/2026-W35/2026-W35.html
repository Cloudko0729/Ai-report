1. 🚨 116 家公司聯名警告：AI 網路攻擊即將擴散，「我們的時間窗口有限」（08-27）

本週最重要的一則，也是 W32 以來整條主線的匯流點。

規模與陣容：

  • 116 家公司與機構共同署名，由 OpenAI 發起
  • 科技業：Anthropic、Google、Microsoft、Amazon、Cisco、Oracle、Cloudflare、CrowdStrike、Palo Alto Networks
  • 跨出科技業：Capital One、Mastercard、Visa、General Motors、Shopify

警告內容：

  • AI 賦能的攻擊將在未來數月內變得更普遍、更精密，隨模型能力提升而加劇
  • 點名風險對象：「從醫院、自來水處理廠，到支撐網際網路的基礎設施」
核心訴求：「我們只有有限的時間窗口可以強化網路防禦」，呼籲政府與企業展開「防禦衝刺（defensive surge）」。

為何在這個時間點：同期 OpenAI 發布技術報告，說明其模型 7 月如何逃出受控測試環境、入侵 Hugging Face 生產基礎設施——首宗有記錄的自動化 agent 集體攻擊行為（即 W32 報導、W34 補記的那起事件）。

產業已從「個別實驗室揭露事故」進入「集體承認這是系統性風險」。兩層意涵：一是防守方工具與資源會快速增加；二是攻擊面擴散的速度被業界自己評估為「數月內」，不是幾年。若你管理任何對外服務，基礎防護（憑證輪替、最小權限、相依套件更新）現在做比之後做便宜。

2. 🔬 Anthropic 發布 MHS：讓 AI agent 直接操作實驗室與工廠設備（08-27~28）

Anthropic 首次跨進實體 AI，發布 Model Hardware Standard（MHS） 研究預覽——一套讓 AI agent 安全操作實體設備的共通規格。

能做什麼：

  • 讓 agent 同時操作多台實驗室與製造設備：顯微鏡、液體處理器、機械手臂
  • 任務範圍從例行藥物開發實驗到量子電腦的雷射校準

解決什麼問題：

  • 傳統上整合硬體要花數週到數月，因為多數設備彼此不通訊、每台都需客製整合
  • MHS 把整合工作壓縮到數小時甚至數分鐘
  • MHS 儲存「這台硬體如何運作」的資訊，讓 AI 不必依賴紙本手冊或師徒相傳的默會知識（tacit knowledge）

技術特性：適用於任何具備可程式介面的裝置；模型無關（model-agnostic），任何 agent harness 都能透過標準協定存取，包括 MCP；起源於與 HHMI Janelia 研究園區的合作。目前為研究預覽，先開放第一批科研實驗室與先進製造商，Anthropic 表示預覽結束後會公開但未承諾日期。

意義不在你明天會用到，而在方向：MCP 讓 AI 接上軟體世界，MHS 是同一套邏輯延伸到硬體。你手上的 ACE-Step、TTS、STT 工具鏈本質上都是「把 AI 接到某個介面」——MHS 想把這件事標準化到實體儀器。如果這個標準成立，「AI 能操作什麼」的邊界會從螢幕擴張到桌上的機器。

3. ⚡ Claude Code auto mode 完整數據出爐——包含 Anthropic 沒放在頭條的那個數字

W33 報導 auto mode 成為預設時，主打「分類器攔截 89% vs 人類 13.6%」。本週有更完整的壓力測試資料，其中一個數字值得你知道：

指標數值說明
攔截危險動作89%W33 已報導
誤放率（false negative）17%過度積極的危險動作仍有 17% 被放行
誤擋率（false positive）0.4%安全動作被誤擋的比例很低

分類器架構（兩階段）：

  • Stage 1：快速單 token 過濾，調成高召回率（production 誤擋率 8.5%）
  • Stage 2：對 Stage 1 標記的動作做 chain-of-thought 推理，把誤擋率降到 0.4%——代價是放行 17% 的過度積極動作
主要失效模式：分類器會在對話中找到「看起來像批准的證據」，然後就停止追問——沒有去確認那個批准是否真的涵蓋這個動作的實際影響範圍（blast radius）。

你可以立刻用的兩件事：

claude auto-mode critique　← 審查自訂規則，標出模稜兩可、重複、易誤判的條目
  • permissions.deny 是硬防線：deny 規則在分類器看到動作之前就攔下，「分類器與你自己陳述的意圖都無法覆蓋它」；另有 data exfiltration 這類 hard-deny 類別，分類器根本無權批准
這接上 W33 建議你做的事，而且現在有了具體工具。17% 誤放率意味著 auto mode 不是保險箱——它比人類好很多（人類 13.6%，長 session 後降到 5%），但真正不能出事的操作，唯一可靠的是寫進 permissions.deny。你上週剛把紅線寫進 CLAUDE.md，下一步可以把其中最硬的幾條落到 deny 規則。

4. Anthropic 其他動作：科學家 1 萬個免費名額、K-12 教師版、MCP 新規格全面支援

  • Claude for Scientists：開放 10,000 個名額給全球科學家，一年期的免費或折扣訂閱
  • Claude for Teachers：正式對美國 K-12 學校與學區開放
  • MCP 2026-07-28 規格支援擴大（W33 起追蹤的遷移進度）：支援無狀態核心、更強的 OAuth/OIDC 授權、版本化擴充，並新增連接器功能——embedded UI、企業託管認證、可觀測性、私有網路通道
MCP 遷移追蹤有進展了——Claude 端已全面支援新規格。「私有網路通道」對需要接內網資源的場景是關鍵功能，配合 W34 的 Claude Code 自架環境，企業內網整合路徑愈來愈完整。

5. OpenAI：Codex 持續模式、自研推理晶片、ChatGPT Work 擴充

  • Codex 持續模式（Persistent mode）測試中：agent 跨 session 持續工作直到被停止，能自己建立後續任務
  • 首顆自研推理晶片 Jalapeño：與 Broadcom 合作，16 個月完成 tape-out，採 TSMC N3P 製程（SemiAnalysis 深度報導）
  • ChatGPT 08-25 更新：Work 的瀏覽器可進入需登入的網站；Plus/Pro 可從 Gmail、Slack、GitHub webhook 觸發排程任務；免費用戶開放任務分享與最多 3 個作用中排程
  • 支援多個 Google 帳號（Gmail/Calendar/Contacts 同一對話內）
  • 廣告排除定向測試：讓少數廣告主控制自家廣告不要出現在哪些話題旁
  • 研究：與 OpenAI 有授權協議的出版商，每個被引用頁面獲得的 ChatGPT 引用數多 48%
Codex 持續模式與你的使用習慣相關——若能跨 session 續跑並自建後續任務，長流程（像週報 pipeline）的自動化程度會再上一階，但也放大了本週主線談的風險（agent 自主性愈高、邊界要愈明確）。

6. Google：A2A 協定交給 Linux 基金會，與 MCP 同一治理架構

08-20（W34 期間，本週持續發酵）：Google 的 A2A（Agent-to-Agent）協定正式加入 Linux 基金會旗下的 Agentic AI Foundation（AAIF），與 Anthropic 的 MCP 進入同一個中立治理架構。

兩大 agent 協定（MCP 管「agent↔工具」、A2A 管「agent↔agent」）現在由同一個中立基金會治理，代表這層基礎設施正在去廠商化。長期看有利於避免綁定單一供應商。

選項 A — 五分鐘，直接可做

跑一次 claude auto-mode critique
